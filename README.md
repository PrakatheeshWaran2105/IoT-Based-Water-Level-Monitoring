# **IoT-Based Water Level Monitoring Using ESP32 and KiwisIoT**

## **About the Project**

The **IoT-Based Water Level Monitoring** is an IoT project designed to monitor the water level in tanks in real time and help prevent water overflow and low-water conditions.

Using an ESP32 microcontroller and an ultrasonic sensor, the system measures the water level and sends the collected data to the KiwisIoT platform through Wi-Fi. Users can monitor the tank's water level remotely through the KiwisIoT dashboard.

By integrating KiwisIoT, this project demonstrates a simple and effective approach to smart water management, real-time monitoring, and IoT-based connectivity.
